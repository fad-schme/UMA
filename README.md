# UMA3-RLM

A personal workspace for UMA3-RLM.

## Setup

Create a Python virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Quick notes
- Project root contains `uma3/` package and examples.
